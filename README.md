# news-digest-pages

Reading pages for the daily morning news digest, published with GitHub Pages:
<https://koalmoik.github.io/news-digest-pages/>

The pages are generated automatically by `render_site.py` in
[koalmoik/news-digest](https://github.com/koalmoik/news-digest); please don't edit them by hand.
The digest itself is written in German.
